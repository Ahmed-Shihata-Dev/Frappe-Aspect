## Frappe Aspect

## Overview

Frappe Aspect adds a resizable split-screen workspace for ERPNext and Frappe — a list on one side and an editable form on the other — so you can browse and edit records without switching pages.

## Features

| | |
|---|---|
| **Aspect View** | A new view mode on every DocType list — open it from the list menu in one click. |
| **List + form together** | Browse records on the left and open the full form on the right without leaving the page. |
| **Live editing** | Select a row to load its form; edit fields and save as you would in the standard form view. |
| **Resizable panes** | Drag the divider to set how much space the list and form each get. |
| **Remember your layout** | Pane width is saved in the browser and restored the next time you open Aspect View. |
| **Reset to center** | One-click control on the splitter returns the layout to a balanced 50/50 split. |
| **Familiar list tools** | Filters, sorting, and search work the same as in the standard Frappe list view. |
| **Clear empty state** | The form pane shows a helpful prompt until you pick a record from the list. |
| **Any DocType** | Works across ERPNext and Frappe — Customers, Items, Sales Orders, and more. |
| **Non-intrusive** | Scoped styling and hooks only activate inside Aspect View; the rest of the desk stays unchanged. |

### Workflow

- Open any list view → choose **Aspect View** from the view menu
- Scan and filter records in the left pane
- Click a row to load its form on the right
- Save changes, pick another row, or switch back to the normal list view anytime
